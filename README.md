# Disney Characters

Aplikacja mobilna wyświetla informacje o postaciach z bajek i filmów Disneya, wykorzystując dane z wybranego REST API.


# Spełnione wymagania na 4

* dwa ekrany: lista postaci oraz ekran z szczegółami wybranej postaci
* obsługa dwóch różnych zapytań REST: pobranie listy i pobranie szczegółów wybranej postaci
* dostępność aplikacji w trybie offline z wykorzystaniem lokalnej bazy danych
* obsługa stanu ładowania danych
* obsługa błędów i wyświetlenie czytelnego komunikatu dla użytkownika
* interfejs użytkownika zrealizowany w Figma
* plik README.md z krótkim opisem
* kilka commitów odwzorowujących przebieg tworzenia aplikacji
